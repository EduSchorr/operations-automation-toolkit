**Coleção de utilitários para eliminar tarefas repetitivas de e-commerce, finanças e atendimento.**

## Utilitários incluídos

- auditoria de cupons duplicados;
- envio de e-mails em lote;
- exportação de contexto do Outlook;
- verificação de pedidos VTEX;
- conciliação de reembolsos Adyen;
- extração de NFS-e em PDF;
- consulta local de informações operacionais;

## Sobre

Coleção de utilitários para eliminar tarefas repetitivas de e-commerce, finanças e atendimento.

Esta é uma **edição sanitizada para portfólio**. Dados de produção, credenciais, endpoints privados, marcas internas e arquivos de execução foram removidos.

## Para clientes brasileiros

O repositório mantém o código técnico principal em inglês, enquanto este arquivo apresenta a solução em português.
